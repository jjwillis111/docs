1. Paste from Word

Click here, then paste In Word: Ctrl+A then Ctrl+C (Mac: Cmd+A, Cmd+C). Here: Ctrl+V (Mac: Cmd+V).

    2. Save it to the site

    Publishing needs the GitHub connection below. Without it, download the file and upload it by hand.

    Upload the downloaded file into your repository's docs folder, then add this entry to documents.json (inside the square brackets, separated from other entries by a comma):

    GitHub connection
    1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens, and click Generate new token.
    2. Under Repository access choose Only select repositories and pick this site's repository.
    3. Under Permissions, set Contents to Read and write. Leave everything else alone.
    4. Generate the token, copy it, and paste it below.

    The token stays in this browser only. It is never written into the site. Anyone without it can open this page but cannot change anything.
